# RK Empires — Intelligent Automations

Marketing site for **RK Empires**. *Automate · Innovate · Elevate.*

A single-page static site built with **Tailwind CSS** (via CDN) and a custom **WebGL gold-aurora** hero background.

## Brand
- **Colors:** Primary Gold `#D4AF37`, Deep Gold `#B8860B`, Black `#0D0D0D`, Dark Gray `#1A1A1A`, Light Gray `#E6E6E6`, White `#FFFFFF`
- **Type:** Playfair Display (headings/logo), Montserrat (body)

## Run locally
```bash
node serve.mjs
# serves the project root at http://localhost:3001
```

## Structure
- `index.html` — the entire site (markup, styles, and the WebGL aurora shader)
- `brand_assets/` — logo and brand guidelines
- `serve.mjs` — tiny static dev server
- `screenshot.mjs` — dev screenshot helper
